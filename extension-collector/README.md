# 麦田采集（只读）

装在你平时登录各平台的浏览器里。每天北京时间 9 点以后的第一次机会，它把各平台创作后台的列表页读一遍，把每篇的阅读、互动和各平台粉丝数交给本机的麦田。

它只读页面上已经显示的文字：不点按钮、不填表、不发布，也不用调试权限。一次只开一个页面，读完就关。

## 读哪些页面

| 平台 | 页面 |
|---|---|
| X | 你的个人主页 |
| 抖音 | 创作者中心首页、作品管理 |
| 小红书 | 创作服务平台首页、笔记管理 |
| B站 | 创作中心的图文管理；粉丝数问 B站自己的公开接口 |
| 公众号 | 后台首页 |

某个平台在这个浏览器里没登录，它记下来以后不再打开；点一下工具栏上的图标会全部重试。

## 安装

1. 把 `token.example.js` 复制成 `token.js`，填麦田 `config.json` 里的 `web.collectToken` 和你的 X 用户名。
2. 浏览器打开扩展管理页（Edge 是 `edge://extensions`），打开“开发人员模式”，点“加载解压缩的扩展”，选这个文件夹。
3. 几个平台分在不同的浏览器配置里登录的话，每个配置各装一次。
4. 点一下工具栏上的图标，马上采一次。图标上出现“✓”是交给麦田了，“!”是麦田没开，下次会补交。

## 数据怎么对上文章

麦田按这些办法把读数对到已登记的文章上，对不上的条目（短帖、还没登记的文章）不入库：

- X：帖子编号对链接
- 公众号：标题
- 其余平台：发布时间，精确到分
